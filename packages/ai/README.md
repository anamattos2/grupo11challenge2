# Pacote de IA

Base instalável para RAG, quatro agentes, orquestração e processamento de imagens.
Esses componentes ainda não estão implementados neste pacote.

A instalação não importa os experimentos nem baixa modelos. O pacote não possui
dependências de execução nesta etapa. A dependência de build está fixada no
`pyproject.toml`; ferramentas futuras terão dependências próprias declaradas.

Consulte [o guia do ambiente](../../docs/desenvolvimento/ambiente.md).
