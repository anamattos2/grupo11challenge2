# Avaliações

Destino de datasets, gabaritos e baselines selecionados. Resultados existentes
permanecem em [RAG/projeto-rag/avaliacao/](../RAG/projeto-rag/avaliacao) e nos
notebooks, registrados no inventário do legado.

Execuções futuras devem registrar versão do código, corpus, modelo, parâmetros
e avaliadores. A existência de um resultado histórico não conclui requisitos.
Dados gerados locais pertencem a `.runtime/`; evidências revisadas podem ser
versionadas aqui após conferir que não contêm dados pessoais.
