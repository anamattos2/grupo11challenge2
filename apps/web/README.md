# Frontend / PWA

Destino da aplicação React + TypeScript. A implementação começa na issue de
inicialização do frontend; ainda não há aplicação executável neste diretório.

Responsabilidades: navegação, formulários, dashboard, chat, fontes, prévia de
comprovantes e política offline. Consumir contratos da API, usando mocks quando
necessário. Cálculos oficiais e autorização pertencem ao backend.

Não há dependências Node declaradas até a escolha da ferramenta de build.
