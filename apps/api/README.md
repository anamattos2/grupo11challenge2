# Backend financeiro

Destino do Django / Django Ninja e PostgreSQL. A implementação começa na issue
de inicialização do backend; ainda não há servidor nem migrations aqui.

Responsabilidades: sessão, autorização, regras financeiras, persistência e
ferramentas determinísticas para os agentes. OpenAPI será a referência das
interfaces HTTP. Nunca aceitar identidade sugerida pelo modelo como autorização.
